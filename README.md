# Voice To Order AI System

## Project Overview

AI-based voice food ordering system using speech recognition and NLP.

## Features

- Voice input
- Speech to text
- Intent detection
- Entity extraction
- Mixed language support
- Add to cart
- Order placement
- Order history

## Tech Stack

- Flask
- Whisper AI
- SQLite
- Bootstrap
- JavaScript

## Installation

pip install -r requirements.txt

python app.py

## Sample Commands

- 2 dosa order karna hai
- add burger
- cancel my order
- repeat last order
